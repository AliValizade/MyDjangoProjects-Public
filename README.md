# Django Projects Collection

A collection of practical **Django web application projects** developed to explore different aspects of backend and web application development with Python and Django.

## 🚀 Projects

This repository contains several independent Django projects:

| Project               | Description                                    |
| --------------------- | ---------------------------------------------- |
| **Ads**               | Classified ads / advertisement web application |
| **blog_website**      | Blog-focused Django web application            |
| **bookstore**         | Bookstore and e-commerce application           |
| **fitzone**           | Fitness-related web application                |
| **notes**             | Notes management application                   |
| **postgersql_docker** | PostgreSQL and Docker related project setup    |
| **restaurant**        | Restaurant-related web application             |

## 🛠️ Technologies

* Python
* Django
* HTML
* CSS
* PostgreSQL
* Docker

## 🎯 Purpose

The projects in this repository were developed as practical exercises for learning and applying Django concepts across different real-world application scenarios.

The collection demonstrates experience with:

* Django project structure
* Database-backed web applications
* Models and data management
* Templates and web interfaces
* E-commerce concepts
* Content management
* Application-specific business logic
* PostgreSQL
* Docker-based development
